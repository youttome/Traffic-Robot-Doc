
متطلبات التشغيل
---------------
- Raspberry Pi
- Python 3.10 أو أحدث
- عدد 2 كاميرا متصلة
- تعريفات OpenCV الخاصة بالكاميرات
- ملفات الموديلات موجودة داخل المشروع


الملفات المهمة
--------------
- finish.py
  الملف الرئيسي لتشغيل النظام

- detectors/
  يحتوي على ملفات اكتشاف المركبات واللوحات

- ocr/
  يحتوي على منطق قراءة اللوحات

- tracker/
  يحتوي على التتبع

- utils/
  يحتوي على الدوال المساعدة

- exports/emergency_request.txt
  الملف الذي يكتب فيه النظام اسم الطريق المطلوب فتحه
===========================================================================================

التثبيت
--------
1) فك ضغط المشروع
2) افتح الطرفية داخل مجلد المشروع
3) ثبت المكتبات المطلوبة:

pip install -r requirements.txt


تثبيت Raspberry Pi aarch64 / Python 3.12
----------------------------------------
إذا كان الجهاز Raspberry Pi يعمل بمعمارية aarch64 وبايثون 3.12 فمن الأفضل استخدام:

python3 -m venv --system-site-packages /tmp/ai-service-venv
source /tmp/ai-service-venv/bin/activate
pip install --no-cache-dir -r requirements-rpi.txt

تمت كتابة requirements-rpi.txt لتجنب المشاكل الشائعة مع نسخ torch / torchvision
ولتقليل استهلاك المساحة عن طريق إعادة استخدام الحزم الموجودة مسبقاً على الجهاز مثل
OpenCV و NumPy و Pillow.


طريقة التشغيل
-------------
لتشغيل النظام على كاميرتين:

python3 finish.py --sources 0 1

المعنى:
- 0 = الكاميرا الأولى
- 1 = الكاميرا الثانية


منطق الإشارة
------------
- cam0 مسؤولة عن ROAD_1
- cam1 مسؤولة عن ROAD_2

دورة الإشارة مدتها 60 ثانية:
- أول 30 ثانية:
  - ROAD_1 أخضر
  - ROAD_2 أحمر

- ثاني 30 ثانية:
  - ROAD_1 أحمر
  - ROAD_2 أخضر

ثم تتكرر الدورة مرة أخرى.


مهم جداً
--------
ليس مطلوباً أن يبدأ برنامج الكاميرات وبرنامج الكنترول في نفس اللحظة.

المطلوب فقط أن يحسب البرنامجان الإشارة من نفس الوقت المرجعي.

بمعنى:
- نفس reference time
- وليس نفس startup time

إذا كان برنامج الكاميرات وبرنامج الكنترول يستخدمان نفس SIGNAL_REFERENCE_EPOCH،
فسوف يحسبان نفس حالة الإشارة حتى لو بدأ كل برنامج في وقت مختلف.


المتغيرات المهمة
----------------
يجب ضبط المتغيرات التالية عند الحاجة:

- SIGNAL_REFERENCE_EPOCH
  الوقت المرجعي الذي يبدأ منه حساب دورة الإشارة

- EMERGENCY_MODEL_PATH
  مسار موديل اكتشاف الطوارئ

- EMERGENCY_CONFIDENCE
  قيمة الثقة الخاصة باكتشاف الطوارئ

- SIGNAL_CYCLE_SECONDS
  مدة دورة الإشارة بالكامل

- SIGNAL_HALF_SECONDS
  مدة كل نصف دورة

===========================================================
ملف طلب فتح الطريق
-------------------
المسار:
exports/emergency_request.txt

شكل الملف:
road=0
ts=2026-04-17T15:42:10

القيم الممكنة:
-1
-2
-0

المعنى:
- ROAD_1 = 1 افتح الطريق الأول
- ROAD_2 = 2 افتح الطريق الثاني
- NONE = 0 لا يوجد طلب فتح
======================================================

المطلوب من سكربت الكنترول
--------------------------
سكربت الكنترول يقرأ الملف:
exports/emergency_request.txt

ثم يتصرف كالتالي:
- إذا كانت القيمة ROAD_1 يفتح ROAD_1
- إذا كانت القيمة ROAD_2 يفتح ROAD_2
- إذا كانت القيمة NONE لا يفعل شيئاً


مخرجات النظام
-------------
يقوم النظام بحفظ ملفات ناتجة داخل exports/ مثل:
- تقارير CSV
- لوج التشغيل
- صور اللوحات
- صور لسيارات الطوارئ عند الحاجة
